# Phase 8 完了報告テンプレ（nokoroa-autopilot）

> マージはユーザーが行う。Claudeは PR をマージしてはいけない。

```
## 実装完了報告

### 要件
[1行で要約]

### チェックリスト
- [ ] 全テスト pass
- [ ] 全専門家 LGTM
- [ ] ブラウザ動作確認完了
- [ ] 品質チェック全 pass（lint）
- [ ] 不要なログ・コメント削除済み（既存ログは保持）

### 変更ファイル
| ファイル | 変更内容 |
|---|---|
| xxx | yyy |

### PR
- URL: [PR URL]
- ブランチ: feature/xxx → main

### スコープ外で見つけた問題（あれば）
- 概要 / 再現手順 / 関連ファイル / 推測原因

### 確認方法
[マージ後にユーザーが確認すべき操作手順]
```

PR URL とともに「マージの準備ができました」と報告して終了。
