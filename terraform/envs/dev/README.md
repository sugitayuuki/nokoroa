# 開発環境（AWS 上には作らない）

開発は AWS ではなくローカルで完結させる方針のため、このディレクトリに `.tf` は置いていません。

- データベースは `nokoroa-backend/docker-compose.yml` の PostgreSQL（pgvector 入り）を使う
- バックエンド・フロントエンド・AI サービスはそれぞれローカルで起動する
- S3 と Secrets Manager に相当する部分は環境変数とローカルファイルで代替する

AWS 上に dev 環境を持たない理由は、個人開発では**環境を増やすほど維持コストと設定のズレが増える**ためです。prod と挙動を突き合わせる必要が出た場合は、`stg/` に書いた方針で使い捨ての環境を立てて確認し、終わったら壊す想定です。

ローカルの起動手順はリポジトリルートの `README.md` を参照してください。
